Les scripts pour Windows
Trois scripts font le travail que cette page ne peut pas faire : un navigateur n'a pas le droit de lire votre registre ni la liste de vos logiciels. Ils sont écrits en PowerShell, donc lisibles dans le Bloc-notes avant d'être lancés.
⬇️ Télécharger le programme
Une seule archive, tout ce qu'il faut dedans. Décompressez-la sur une clé USB, et double-cliquez Migration PC.bat sur le PC source.
Ne prenez pas les fichiers un par un. Les scripts ont tous besoin de lib-detection.ps1 à côté d'eux, et le .bat a besoin du dossier scripts : un fichier isolé s'arrête au démarrage. C'est pour ça qu'il n'y a qu'un seul bouton.
Ma configuration
Les intitulés des pilotes portent le modèle, et les boutons « Rechercher » visent le support du constructeur au lieu de mots génériques. Tout est facultatif, et reste dans ce navigateur.
Réinitialiser
Décocher toute la checklist
Remet la progression à zéro sur les trois onglets. Le profil chargé, votre configuration matérielle et les lignes que vous avez écartées sont conservés.
Remettre le site à zéro
Efface tout ce que ce navigateur a mémorisé — progression, configuration matérielle, lignes écartées, profil importé — et revient au profil d'exemple. Vos fichiers exportés ne sont pas touchés.
