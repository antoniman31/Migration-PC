Les scripts pour Windows
Trois scripts font le travail que cette page ne peut pas faire : un navigateur n'a pas le droit de lire votre registre ni la liste de vos logiciels. Ils sont écrits en PowerShell, donc lisibles dans le Bloc-notes avant d'être lancés.
Prenez le dossier entier, pas un fichier isolé. Les trois scripts ont besoin de lib-detection.ps1 à côté d'eux, et les deux .bat du script qu'ils lancent. Le plus simple est de télécharger tout le dossier en une fois, de le poser sur une clé USB avec cette page, et de double-cliquer le premier .bat sur l'ancien PC.
Ma configuration
Les intitulés des pilotes portent le modèle, et les boutons « Rechercher » visent le support du constructeur au lieu de mots génériques. Tout est facultatif, et reste dans ce navigateur.
Deux questions pour adapter la liste
La checklist couvre plusieurs situations qui ne demandent pas les mêmes étapes. Répondre prend dix secondes, et vous pourrez changer d'avis à tout moment avec le sélecteur en haut de page.
